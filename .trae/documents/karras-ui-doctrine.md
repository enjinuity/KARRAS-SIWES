## 1. Core Direction

KARRAS should feel like a serious systems workspace, not a startup presentation layer.

The logo defines the product language:

- black-first
- geometric
- restrained
- premium
- calm
- authoritative

## 2. Product Rules

### 2.1 Shell Before Marketing

- the app shell must feel stable and architectural
- navigation should expose work surfaces, not module slogans
- `Workspace` remains the primary work entry

### 2.2 Work Pages, Not Demo Pages

- operational pages must look like software used by staff and students
- use tables, queues, forms, status rows, and side panels
- avoid oversized storytelling cards inside product pages

### 2.3 Quiet Branding

- branding should come through typography, alignment, spacing, and restraint
- avoid loud gradients, glowing accents, and decorative sections
- white on black should carry most of the interface weight

### 2.4 Module Positioning

- modules live inside KARRAS
- the global shell should not loudly rename itself around any single module
- `Bridge` should not replace `Workspace` in primary navigation

## 3. Visual Language

### 3.1 Color

- primary background: near-black
- primary text: white and light zinc
- secondary text: subdued gray
- accent color: minimal and functional only

### 3.2 Form

- use crisp geometry
- moderate radius only where it helps structure
- prefer bordered planes over glowing cards

### 3.3 Typography

- headlines are short and deliberate
- interface copy is compact and operational
- avoid long explanatory copy in work surfaces

### 3.4 Motion

- minimal
- fast
- supportive
- never theatrical

## 4. Information Architecture

### 4.1 Global Navigation

- Home
- Workspace
- Reports
- Compare
- Methodology
- Access

### 4.2 Virtual Lab Structure

- Overview
- Course
- Student
- Grading

These pages should behave like institutional software surfaces, not conceptual feature showcases.

## 5. Anti-Patterns

Do not reintroduce:

- hero-heavy module promotion in the main shell
- presentation-style “why it matters” cards inside work pages
- loud module names in primary navigation
- excessive glow, gradient, or decorative framing
- product copy that reads like a pitch instead of a tool
